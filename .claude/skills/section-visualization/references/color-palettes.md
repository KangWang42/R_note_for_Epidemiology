# 配色选择

## 先匹配变量语义

| 数据语义 | 配色类型 | 核对重点 |
|---|---|---|
| 无序分类 | 定性色板 | 类别数、相邻颜色区分、灰度和色觉差异 |
| 有序或连续 | 顺序色板 | 亮度是否单调、极值是否可见 |
| 有意义中点两侧 | 发散色板 | 中点是否由问题定义，两个方向是否平衡 |
| 强调少数组 | 中性色加重点色 | 未强调组仍可辨认，重点色不暗示不存在的好坏 |

`viridis` 系列、ColorBrewer 和手工色板都只是候选。实际可读性还受背景、线宽、面积、投影、打印和相邻颜色影响，必须在最终尺寸检查。

## 使用规则

- 同一变量跨图保持颜色含义一致。
- 不仅依赖红/绿或颜色深浅；增加形状、线型、标签或分面。
- 类别多到无法稳定区分时，优先重组问题、直接标注或分面，不自动生成更多颜色。
- 发散色板只在零值、目标值或基准值具有实际意义时使用。
- 期刊名称色板来自第三方包时，核对包文档与许可证，不写成期刊官方要求或质量保证。
- 地图和热图核对缺失值、超界值和插值方式的显示，不让缺失与最低值同色。

## R 接口

- `ggplot2::scale_*_viridis_c()` / `_d()`：连续或离散的 viridis 候选。
- `ggplot2::scale_*_brewer()` / `scale_*_distiller()`：ColorBrewer 定性、顺序或发散色板。
- `ggplot2::scale_*_manual()`：按稳定类别名称显式映射颜色。
- `colorspace`：构建和诊断基于感知空间的色板。

函数名、色板容量与参数以当前官方文档为准。教程应展示最终图和冗余编码，而不是只列十六进制颜色。
