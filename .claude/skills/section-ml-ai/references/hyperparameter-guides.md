# 超参数与调优

## 先决定是否需要调优

调优是模型开发的一部分，不是每篇教程的必选章节。只有基线已建立、评价口径已锁定且计算预算允许时才调优。参数名、默认值和允许范围必须以文章使用的包、学习器和版本为准。

## 搜索空间的组织

| 模型族 | 优先核对的复杂度轴 | 常见交互 |
|---|---|---|
| 随机森林 | 候选变量数、叶节点/节点最小样本、树数 | 树数主要影响稳定性和成本；节点大小与候选变量数共同影响偏差方差 |
| 梯度提升树 | 学习率、迭代数、树深/叶数、行列采样、正则化 | 学习率与迭代数必须联合考虑；早停需要独立验证折 |
| 支持向量机 | 核、惩罚、核尺度 | 惩罚与核尺度通常按对数尺度搜索；预处理必须在折内 |
| 正则化回归 | 混合参数、惩罚强度 | 惩罚路径应由训练折确定，类别编码和标准化不能泄漏 |
| 神经网络 | 结构、学习率、批量、正则化、训练轮次 | 早停、随机初始化和硬件会影响结果与复现性 |

表中只给搜索维度，不给跨包通用的固定范围。范围应结合特征数、样本量、资源预算、参数变换以及官方约束确定。

## 重采样合同

- 调参和模型选择只使用训练数据；测试集保持封存。
- 数据存在受试者、中心、家庭或重复测量时按簇分组重采样。
- 时间预测按时间顺序切分，不能随机打乱未来与过去。
- 预处理、缺失插补、特征选择和类别平衡均放入重采样流程。
- 多模型比较使用相同重采样实例和预设指标；随机搜索记录预算、种子和搜索空间。
- 数据较少且调参偏差可能明显时使用嵌套重采样；不能把调参折的最佳表现当作最终泛化性能。

## 终止与失败

记录失败组合、收敛警告和资源耗尽，不通过静默捕获只保留成功组合。搜索停止可由预设评估次数、时间预算、早停规则或性能稳定性决定。最终参数应在完整训练集上重拟合，并只在封存测试集或外部数据上评价一次。
