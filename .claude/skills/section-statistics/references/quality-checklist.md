# 统计教程检查表

## 方法

- [ ] 已区分描述、关联、预测和因果目标。
- [ ] 已定义 estimand、时间零点、结局、分析人群和效应尺度。
- [ ] 理论保证写明成立条件，未把稳健标准误等同模型无条件正确。
- [ ] 与相近方法的差异按问题和风险集解释，不按“谁更显著”选择。
- [ ] 会改变 estimand 或效应解释的易混淆方法已在首次模型调用前定位，比较覆盖数据要求、假设、诊断和改用条件。
- [ ] 经验阈值和参数有来源或明确标为教学/敏感性设定。

## 数据与代码

- [ ] 模拟机制与方法问题一致，变量、事件和删失不是独立拼接。
- [ ] 所有可运行代码已在当前环境实跑，函数签名和返回字段已核对。
- [ ] warning、NA、空结果、收敛失败和样本量变化已逐项处理。
- [ ] 图和表来自代码对象，输出后有解释。
- [ ] 效应量、95% 区间和有意义的绝对量得到报告。

## 表达与证据

- [ ] 缩写首次出现给出全称，术语全文一致。
- [ ] 观察性结果没有无条件因果措辞。
- [ ] 引文、DOI/PMID、包文档和当前版本均可核验。
- [ ] 段落完成论证，不用短句列表替代全部解释。
- [ ] 常见错误说明后果和修正，而不只列名称。

## 页面

- [ ] 运行 `audit_tutorial.py` 无 ERROR。
- [ ] 目标文章定向渲染成功，完整日志无未解释 warning/error。
- [ ] `_quarto.yml`、生成的 `sections/statistics.qmd` 和 `index.qmd` 已同步。
- [ ] 图片存在、替代文本准确、图中文字和表格在移动端可读。
- [ ] 示意图确实表达了表格难以呈现的分支或关系，未与比较表逐字重复。
