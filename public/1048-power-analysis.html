样本量计算的起点

样本量不是由“研究类型”或某个通用效应量单独决定的。可复核的计算必须先锁定研究问题、主要 estimand、主要结局、组间分配、分析方法和可接受的不确定性。软件只能求解已经定义清楚的统计问题，不能替研究者补齐设计。

一份计算说明至少需要以下输入。

输入 需要明确的内容 常见来源
研究设计 平行、配对、交叉、聚类、重复测量、队列、病例对照或诊断研究 PROTOCOL 或研究方案
主要结局 连续、二分类、计数、时间结局或预测性能 主要终点定义
目标效应 均值差、风险差、风险比、优势比、风险比、相关系数或最小临床重要差异 既往同人群研究、预实验、专家共识
变异或基线风险 标准差、组内相关系数、对照组率、事件率、删失率 外部研究或历史数据
错误率 双侧或单侧 α\alpha、目标功效 1−β1-\beta、多重性策略 分析计划
实施参数 分配比、失访、不依从、聚类大小、入组期和随访期 实际研究条件

效应量不应只按“小、中、大”模板选择。Cohen 的经验阈值适合教学和敏感性分析，不是临床重要性的替代。正式计算应优先使用有明确单位的目标差异、基线风险和变异参数，并展示合理范围内的敏感性分析。

四类计算思路

检验功效法

给定效应、显著性水平和目标功效，求达到预定检验能力所需的样本量。两组均值、两组率、相关、方差分析和回归的经典公式多属于这一类。

估计精度法

目标不是“得到显著差异”，而是把均值、率、灵敏度或风险的置信区间控制到预设宽度。描述性调查、患病率估计、登记研究和诊断准确性研究常用精度法。

事件数法

生存分析和二分类预测模型的有效信息主要由事件数量决定。总样本量需要结合事件发生率、入组期、随访期和删失率，从目标事件数反推，不能只报告入组人数。

模拟法

当设计含重复测量、非正态结局、复杂相关结构、非线性模型、适应性规则或多阶段流程时，解析公式可能不适用。模拟法按拟采用的完整分析流程反复生成数据，以达到目标拒绝率或区间精度的最小样本量作为结果。

Base R 的常用函数

两独立样本均值

假设主要结局的目标均值差为 5，组内标准差为 10，采用双侧检验，α=0.05\alpha=0.05，目标功效为 0.80。power.t.test() 返回的是每组样本量，实际招募数应向上取整。

mean_design <- power.t.test(
  delta = 5,
  sd = 10,
  sig.level = 0.05,
  power = 0.80,
  type = "two.sample",
  alternative = "two.sided"
)

power.t.test() 的两独立样本计算假定两组样本量相等，并使用共同标准差。若预期方差不等或分配比不是 1:1，应使用与最终 Welch 检验或模型一致的方法，例如 powerSurvEpi::ssizeWelchT()、专用软件或模拟。

sD=s12+s22−2rs1s2 s_D=\sqrt{s_1^2+s_2^2-2rs_1s_2}

换算。相关系数的不确定性应进入敏感性分析。

between.var 是组均值的方差，within.var 是共同组内方差。函数假定各组样本量相等，回答总体 F 检验的功效，不等同于某个指定组间对比的功效。

pwr 包的经典检验

pwr 使用标准化效应量统一实现常见检验。标准化便于比较，但正式方案仍应记录效应量如何从原始尺度得到。

library(pwr)

相关、卡方与多元回归

cor_design <- pwr.r.test(
  r = 0.30,
  sig.level = 0.05,
  power = 0.80,
  alternative = "two.sided"
)

chisq_design <- pwr.chisq.test(
  w = 0.30,
  df = 1,
  sig.level = 0.05,
  power = 0.80
)

reg_design <- pwr.f2.test(
  u = 5,
  f2 = 0.15,
  sig.level = 0.05,
  power = 0.80
)

data.frame(
  design = c("相关", "卡方", "多元回归"),
  required_n = c(
    ceiling(cor_design$n),
    ceiling(chisq_design$N),
    ceiling(reg_design$v + reg_design$u + 1)
  )
)
    design required_n
1     相关         85
2     卡方         88
3 多元回归         92

pwr.f2.test() 中的 u 是被检验的分子自由度，v 是残差自由度；总样本量为 u + v + 1。效应量

f2=Rfull2−Rreduced21−Rfull2 f^2=\frac{R^2_{\mathrm{full}}-R^2_{\mathrm{reduced}}}{1-R^2_{\mathrm{full}}}

应对应“完整模型相对于约简模型新增部分”的检验，而不是机械套用全部模型的 R2R^2。

精度导向的计算

估计均值

希望双侧 95% 置信区间的半宽不超过 2，预期标准差为 12，可用正态近似得到初始样本量。

alpha <- 0.05
sd_expected <- 12
margin <- 2

n_mean_precision <- ceiling(
  (qnorm(1 - alpha / 2) * sd_expected / margin)^2
)

n_mean_precision
[1] 139

小样本时应使用 t 分布迭代修正；若标准差来自很小的预实验，也应对其不确定性进行保守调整。

估计率

p_expected <- 0.20
margin <- 0.03

n_prop_precision <- ceiling(
  qnorm(0.975)^2 * p_expected * (1 - p_expected) / margin^2
)

n_prop_precision
[1] 683

不知道预期率时，p_expected = 0.5 给出最大方差下的保守结果。抽样总体有限且抽样比例较高时，再使用有限总体校正；复杂抽样还需乘以设计效应。

聚类、重复测量与多中心设计

设计效应近似

当每簇平均纳入 m‾\bar m 人、组内相关系数为 ρ\rho 时，等簇大小下的经典设计效应为

DE=1+(m‾−1)ρ. \mathrm{DE}=1+(\bar m-1)\rho. 

individual_n <- 240
mean_cluster_size <- 20
icc <- 0.03

design_effect <- 1 + (mean_cluster_size - 1) * icc
cluster_adjusted_n <- ceiling(individual_n * design_effect)
clusters_required <- ceiling(cluster_adjusted_n / mean_cluster_size)

data.frame(
  design_effect = design_effect,
  adjusted_individuals = cluster_adjusted_n,
  minimum_clusters = clusters_required
)
  design_effect adjusted_individuals minimum_clusters
1          1.57                  377               19

该公式只适合作为初步近似。簇数过少、簇大小不等、分层随机、基线调整和纵向重复测量都会改变方差。正式聚类试验应以“簇数”和“每簇人数”同时规划，并使用 clusterPower、CRTSize、powerlmm 或基于拟采用混合模型/GEE 的模拟。

重复测量

重复测量的功效取决于时间点数量、同一受试者内相关结构、时间趋势、处理与时间交互、失访模式和最终模型。把所有观测数当作独立样本会高估信息量。longpower 适合部分线性混合模型场景，powerlmm 面向纵向多层设计，simr 可基于 lme4 模型进行模拟功效分析。

预测模型的样本量

“每个变量 10 个事件”不是普遍适用的预测模型样本量规则。候选预测参数数目、结局频率、预期模型解释度、允许的过拟合和总体风险估计精度都应进入计算。pmsampsize 按 Riley 等提出的标准支持连续、二分类和生存结局模型开发。

library(pmsampsize)

# 二分类结局：24 个候选参数、结局率 17.4%、
# 预期 Cox-Snell R² 为 0.288
pmsampsize(
  type = "b",
  csrsquared = 0.288,
  parameters = 24,
  prevalence = 0.174
)

这里的 parameters 是候选回归参数数，而不只是变量个数。一个多分类变量、样条项和交互项都可能占用多个参数。模型外部验证的样本量还应根据校准、判别和目标人群风险分布的精度另行规划。

失访、不依从与多重性

失访膨胀

若解析计算得到需要完成随访的样本量 nn，预期失访比例为 dd，招募量为

nrecruit=⌈n1−d⌉. n_{\mathrm{recruit}}=\left\lceil\frac{n}{1-d}\right\rceil. 

completed_per_group <- ceiling(prop_design$n)
loss_to_follow_up <- 0.15

recruit_per_group <- ceiling(completed_per_group / (1 - loss_to_follow_up))
total_recruitment <- 2 * recruit_per_group

c(per_group = recruit_per_group, total = total_recruitment)
per_group     total
      115       230

不能简单写成 n * 1.15，因为该式只补回原样本量的 15%，不足以抵消招募总数中 15% 的流失。若失访与组别或预后有关，单纯扩大样本量不能消除偏倚，还需要预防、追踪和缺失数据策略。

多个主要终点、中期分析、多组比较或亚组交互会改变显著性水平分配。应先确定层级检验、门控、Bonferroni/Holm、组序贯边界或其他多重性方案，再计算样本量，不能先按 α=0.05\alpha=0.05 计算后临时增加主要检验。

模拟法的最小流程

复杂设计的模拟功效分析应复用最终分析流程，而不是只模拟一个简化 t 检验。

  1. 按候选样本量生成协变量、结局、聚类和缺失过程；
  2. 使数据生成机制覆盖主情景和关键偏离情景；
  3. 每次模拟运行计划中的完整模型和检验；
  4. 记录收敛失败、不可估计和拒绝原假设的比例；
  5. 增加模拟次数，给功效估计报告 Monte Carlo 误差；
  6. 选择达到目标功效且实施可行的最小样本量，并保留模拟代码。

如果 1,000 次模拟得到功效估计 p̂=0.80\hat p=0.80，其 Monte Carlo 标准误约为

0.8(1−0.8)1000≈0.013. \sqrt{\frac{0.8(1-0.8)}{1000}}\approx0.013.

这说明“模拟功效 80%”本身也有数值误差。临界样本量附近应增加模拟次数并报告不确定性。

计算结果的报告模板

主要结局为第 12 周连续量表变化，主要比较采用双侧两独立样本 t 检验。根据同目标人群既往研究，组内标准差预计为 10 分；研究设定最小临床重要差异为 5 分，显著性水平为 0.05，功效为 0.80，两组按 1:1 分配。计算得到每组所需完成随访人数，并向上取整；再按预期 15% 失访率使用 n/(1−d)n/(1-d) 膨胀招募量。另以标准差 8–12 分和目标差异 3–5 分进行敏感性分析。

实际报告应把模板中的每个数字替换为可核验来源，并说明使用的函数或软件版本。若主要分析不是 t 检验，样本量方法也必须随之改变。

常见错误

错误 影响 处理
用中等效应量代替临床目标差异 计算与研究决策脱节 回到原始单位和最小临床重要差异
按最终计划之外的简单检验计算 实际模型功效未知 使用与主要分析一致的解析或模拟方法
只给总样本量，不给事件数或簇数 无法判断有效信息 同时报告事件、簇和每簇人数
把失访率直接加到原样本量 招募量不足 使用 n / (1 - d)
忽略多重主要终点和中期分析 实际 I 类错误率高于设计值 先定多重性方案，再计算
仅报告一个输入情景 结果对不确定参数过度敏感 报告预设的敏感性范围
用事后功效解释非显著结果 只是 P 值的变换，信息增量有限 报告效应量与置信区间
