目标试验模拟首先是一种设计框架

目标试验模拟（target trial emulation）要求先写出希望随机开展但现实中未开展的试验协议，再说明观察性数据如何逐项模拟该协议。它不是某个回归函数，也不是在普通队列分析标题前加上“目标试验”四个字。

这个框架最重要的作用，是迫使研究者在看结果前明确：谁在何时有资格进入、比较哪些治疗策略、何时开始随访、结局如何判定、希望估计什么对比，以及观察性治疗分配和失访如何调整。它能减少可避免的设计偏倚，但不能让观察性数据自动等同随机试验。未测量混杂、治疗测量误差、阳性不足和不可比的医疗决策仍然存在。

一份完整的目标试验协议

至少应逐项定义以下内容：

协议要素 需要明确的问题
资格标准 哪些人在时间零点满足纳入、排除条件？条件能否只用当时及此前信息判断？
治疗策略 是点治疗、持续治疗、动态规则还是允许宽限期的启用策略？允许哪些治疗版本？
分配程序 理想试验如何随机分配？观察性模拟如何控制基线或时变混杂？
时间零点 资格判定、治疗策略分配和随访开始是否发生在同一时点？
随访 从何时开始，到结局、竞争事件、失访、方案结束中的哪一个时点结束？
结局 结局定义、判定窗口和数据来源是什么？
因果对比 ITT 类效应、per-protocol 类效应、风险差、风险比、RMST 差还是其他 estimand？
分析计划 如何调整混杂、删失、策略偏离、重复入组和不确定性？

资格、分配和随访三者未对齐，是很多 immortal time bias 和选择偏倚的来源。例如把“未来 90 天内开始治疗”定义为暴露，却从今天开始计算该组随访，会要求个体必须存活到治疗开始才能归入治疗组。

本教程的目标试验

先实现最容易核验的点治疗试验，而不是直接跳到复杂动态策略。

  • 目标人群：40–80 岁、此前未用目标治疗且无目标结局的人。
  • 时间零点：满足资格并作出治疗决策的索引日。
  • 策略：索引日启用治疗，与索引日不启用治疗。
  • 分配：理想试验随机分配；观察性模拟用基线 IPTW 调整已测量混杂。
  • 随访：索引日起 2 年，直至结局、删失或行政随访结束。
  • 结局：首次目标事件。
  • Estimand：目标人群中 2 年风险差，作为 ITT 类点治疗对比。

这是基线策略示例，不涉及治疗转换和依从性变化，因此不需要克隆—人工删失—加权。后文会说明何时才需要这些步骤。

生成与协议一致的观察性队列

严重度和合并症同时影响治疗与结局，形成基线混杂。事件时间取决于治疗和基线风险，删失独立生成，随访从同一个索引日开始。

set.seed(20260731)
n <- 2200
horizon <- 2

trial_data <- tibble(
  id = seq_len(n),
  index_date = as.Date("2020-01-01") + sample(0:730, n, replace = TRUE),
  age = runif(n, 40, 80),
  severity = rnorm(n),
  comorbidity = rbinom(n, 1, 0.34)
) |>
  mutate(
    treatment_probability = plogis(
      -0.45 + 0.70 * severity + 0.55 * comorbidity +
        0.018 * (age - 60)
    ),
    treatment = rbinom(n, 1, treatment_probability),
    event_rate = 0.20 * exp(
      -0.45 * treatment + 0.50 * severity +
        0.40 * comorbidity + 0.018 * (age - 60)
    ),
    event_time = rexp(n, rate = event_rate),
    censor_time = runif(n, min = 1.5, max = 3.0),
    follow_time = pmin(event_time, censor_time, horizon),
    event = as.integer(
      event_time <= censor_time & event_time <= horizon
    )
  ) |>
  select(
    id, index_date, age, severity, comorbidity,
    treatment, follow_time, event
  )

trial_data |>
  summarise(
    participants = n(),
    treated = sum(treatment),
    events = sum(event),
    minimum_followup = min(follow_time),
    maximum_followup = max(follow_time)
  )

)

诊断要覆盖治疗前的协变量分布、倾向评分重叠、权重尾部和有效样本量。绝对 SMD 0.1 是辅助标尺，不是证明可交换性的检验。目标试验协议还应列出数据库中没有测量、但可能同时影响治疗和结局的因素，并说明定量偏倚分析或负对照等补充策略。

估计 2 年标准化风险

以下用 ATE 权重拟合加权 Kaplan–Meier 曲线。因为模拟中的删失独立于治疗和预后，所以示例没有额外删失权重；真实研究若删失依赖已观测病史，应加入逆概率删失权重。

trial_analysis <- trial_data |>
  mutate(weight = trial_weight$weights)

weighted_survival <- survfit(
  Surv(follow_time, event) ~ treatment,
  data = trial_analysis,
  weights = weight
)

time_grid <- seq(0, horizon, by = 0.1)
survival_summary <- summary(
  weighted_survival,
  times = time_grid,
  extend = TRUE
)

survival_plot_data <- tibble(
  time = survival_summary$time,
  survival = survival_summary$surv,
  strategy = factor(
    survival_summary$strata,
    levels = c("treatment=0", "treatment=1"),
    labels = c("索引日不启用", "索引日启用")
  )
)

示例输出只验证从协议到估计的代码链。加权 survfit() 的常规标准误没有完整传播估计权重带来的不确定性，正式分析可按受试者 bootstrap，并在每次重抽样中重新估计治疗权重、删失权重和风险曲线。报告风险差时还应给出置信区间，不应只报告一个小数。

为什么一个普通 Cox 回归还不够

coxph(Surv(time, event) ~ treatment + covariates) 可能是某个调整分析，但仅有这行代码不能证明完成了目标试验模拟。还必须核验：

  • 暴露、资格和随访是否在同一时间零点定义；
  • 暴露是否引用未来信息；
  • 比较的是策略还是含糊的“曾经治疗”；
  • 目标效应是 HR 还是固定时间风险差、风险比或限制平均生存时间差；
  • 混杂、删失、竞争事件和策略偏离如何对应协议；
  • 数据是否真正支持两种策略。

HR 也不是固定时间风险比。若临床问题关心 2 年结局，直接报告标准化 2 年风险及其差异通常更易解释。

何时需要克隆—删失—加权

若策略允许宽限期，例如“入组后 30 天内启用治疗”与“30 天内不启用”，一个人在宽限期早期可能同时与两种策略相容。立即把其归入未来实际策略会使用未来信息。克隆—人工删失—加权（clone–censor–weight）的一般思路是：

  1. 在时间零点把每个符合条件者复制到所有当时相容的策略；
  2. 当某个副本的观察治疗史偏离其分配策略时，对该副本人工删失；
  3. 用人工删失的逆概率权重调整由依从过程造成的选择；
  4. 按原始个体处理克隆间相关，并在 bootstrap 中从个体层面重抽样。

克隆不是增加样本量，也不用于点治疗对比。人工删失模型需要使用删失前的治疗与协变量历史；极端权重同样会暴露阳性不足。

序贯试验模拟

当个体在多个时间点可重复满足资格，可在每个时间点启动一个嵌套试验：当时符合资格且尚未治疗者进入该次试验，比较此刻启用与不启用，随后将各次试验合并分析。必须：

  • 在每次试验基线重新测量协变量并定义治疗；
  • 让同一个人可进入多次试验，但方差按人聚类；
  • 处理不同日历时间、既往试验经历和后续转换；
  • 明确合并后 estimand 是各试验基线分布的何种平均。

序贯试验、克隆—删失—加权和基线点治疗是不同设计工具。应使用能模拟目标协议的最简单方法，不能因为“更高级”而机械叠加。

ITT 类与 per-protocol 类效应

观察性模拟中没有真实随机分配，因此“ITT 类”通常指按时间零点观察到的启用决策分组，忽略后续转换；它仍需基线可交换性。per-protocol 类效应要求比较持续遵循策略的结果，通常要处理时变依从、时变混杂和信息性人工删失。两者对应不同问题，不能用同一暴露编码同时声称估计了二者。

竞争事件和缺失数据

死亡等竞争事件不能总是当作普通删失。治疗可能同时影响目标事件和竞争事件，因此应预先定义总效应、直接效应、复合结局或其他合适 estimand，并使用相容的风险估计。基线协变量缺失、治疗记录缺口和结局失访也需要分别制定插补、加权或敏感性分析，而不是在建模时统一删除。

常见失败模式

  1. 根据随访期间的治疗定义组别，却从更早时点开始随访。
  2. 先找到治疗者的治疗日，再给未治疗者随意指定时间零点。
  3. 用未来依从性或存活情况决定基线资格。
  4. 把治疗名称写清，却没有定义剂量、频率、宽限期和允许转换。
  5. 只拟合一个 Cox 模型，没有列出目标试验协议。
  6. 使用克隆后把所有副本当作独立个体。
  7. 人工删失后不加权，或权重模型使用删失后的信息。
  8. 报告一个 HR，却把结论写成固定时间风险下降。
  9. 因设计形式接近试验而省略未测量混杂和阳性限制。

报告清单

  • 将目标试验协议与观察性模拟逐项并列；
  • 给出资格判定、治疗分配和随访开始的同日对齐证据；
  • 报告样本筛选流程、每种策略人数、事件和删失；
  • 说明 estimand、绝对风险时间点和标准化人群；
  • 完整记录治疗、删失或依从权重模型及诊断；
  • 对重复入组、克隆和方差相关性作适当处理；
  • 报告未测量混杂、结局误分、阳性和竞争事件敏感性分析；
  • 按 TARGET 报告建议区分目标试验要求与实际模拟偏离。
