## 2. 必须遵循的标题层次 (CRITICAL)
- 一级标题 (`##`) 是生成目录的唯一途径。
- 文章必须包含至少 3 个一级标题。
- 单个 `#` 标题由 Quarto 自动生成，禁止手动添加。

## 3. 章节结构规范
1. `## 任务目标与典型场景`: 解决的具体问题、适用场景、工具对比表格。
2. `## 准备工作`: 必要工具版本、R 包安装、外部依赖配置。
3. `## 基础操作流程`: 分步骤详解（目标、代码实现、逻辑解释、输出检查）。
4. `## 实战案例`: 提供完整的真实案例（背景、数据来源、完整流程、结果说明）。
5. `## 进阶技巧`: 批量处理、错误处理、性能优化。
6. `## 常见问题与解决方案`: 系统化的排错指南（表现、原因、解决方法、预防措施）。
7. `## 效率与规范`: 文件命名规范、目录组织、代码风格、版本控制。
8. `## 相关工具`: 同类工具对比、配套工具推荐、推荐阅读。

## 4. 写作规范
- **操作导向**: 以 "如何做" 为主线，每步都可直接操作。
- **路径规范**: 优先使用相对路径 + `here` 包，避免硬编码绝对路径。
- **验证清单**: 每个关键步骤提供验证代码和检查清单。
- **跨平台**: 优先考虑跨平台方案，说明平台差异。
