多重插补解决的不是“空格”本身

多重插补（multiple imputation, MI）用多个合理值表达缺失数据的不确定性。标准流程是：

  1. 从插补模型的预测分布生成 (m) 个完整数据集；
  2. 在每个数据集上执行同一分析；
  3. 用 Rubin 法则合并点估计、组内方差和组间方差。

它与均值填补等单次插补的根本区别是：MI 不把填入值当作已知真值。多重插补也不能修复不合理的研究设计、未测量混杂或定义错误的变量。

先界定缺失机制

机制 条件性定义 分析含义
MCAR 缺失概率不依赖已观测和未观测数据 完整案例分析可无偏，但通常损失精度
MAR 给定已观测信息后，缺失概率不再依赖缺失值本身 合理指定的 MI、加权等方法可得到有效推断
MNAR 即使给定已观测信息，缺失仍依赖未观测值 需要不可由观测数据单独识别的假设与敏感性分析

这些机制是关于概率分布的假设，不能仅凭一次显著性检验“证明 MAR”。缺失模式、临床流程和数据采集机制应共同用于论证。若 MNAR 合理，MI 仍可作为 MAR 主分析，但要增加 delta 调整、模式混合模型或选择模型等敏感性分析。

插补模型应服务于最终分析

先写出实质分析模型，再设计插补模型。一般应考虑纳入：

  • 最终分析中的结局、暴露、混杂因素和分层变量；
  • 与缺失概率或缺失值相关、但不一定进入最终模型的辅助变量；
  • 设计变量，如中心、簇、随访时间和抽样权重；
  • 分析模型中的非线性项、交互项和重复测量结构。

不应把受试者 ID 当作普通连续预测变量，也不能忽略多水平数据结构。完全条件指定（fully conditional specification, FCS）逐变量建立条件模型，使用方便，但这些条件模型未必自动对应一个联合分布；方法选择仍须符合变量类型和数据范围。

构造一个 MAR 示例

下面先生成完整数据，再让 BMI 的缺失概率依赖已观测的年龄、吸烟和结局，让结局缺失概率依赖年龄和吸烟。这个机制是为演示而明确设定的 MAR，不代表真实研究可以由数据直接确认 MAR。

set.seed(20260731)

n <- 500
complete_data <- tibble(
  id = seq_len(n),
  age = round(rnorm(n, 52, 11), 1),
  sex = factor(rbinom(n, 1, 0.52), labels = c("男", "女")),
  smoke = factor(rbinom(n, 1, 0.28), labels = c("否", "是"))
) |>
  mutate(
    bmi = round(23 + 0.05 * (age - 50) +
      1.1 * (smoke == "是") + rnorm(n, sd = 3.2), 1),
    outcome = 10 + 0.32 * bmi + 0.04 * age +
      0.9 * (smoke == "是") - 0.4 * (sex == "女") +
      rnorm(n, sd = 2.5)
  )

p_miss_bmi <- plogis(-2.2 +
  0.025 * (complete_data$age - 50) +
  0.35 * (complete_data$smoke == "是") +
  0.08 * (complete_data$outcome - mean(complete_data$outcome)))

p_miss_outcome <- plogis(-2.6 +
  0.03 * (complete_data$age - 50) +
  0.45 * (complete_data$smoke == "是"))

analysis_data <- complete_data |>
  mutate(
    bmi = replace(bmi, runif(n) < p_miss_bmi, NA_real_),
    outcome = replace(outcome, runif(n) < p_miss_outcome, NA_real_)
  )

配置 mice

先让 mice() 生成默认方法和预测矩阵，再明确修改。这里不插补 id，也不让它预测其他变量；连续变量使用 predictive mean matching（PMM）。PMM 可减少越界值，但并非在所有情形下都优于参数模型。

initial <- mice(analysis_data, maxit = 0, printFlag = FALSE)
method <- initial$method
predictor_matrix <- initial$predictorMatrix

method["id"] <- ""
method["age"] <- ""
method["sex"] <- ""
method["smoke"] <- ""
method[c("bmi", "outcome")] <- "pmm"

predictor_matrix[, "id"] <- 0
predictor_matrix["id", ] <- 0

年龄、性别和吸烟在这个示例中完整，因此不需要插补，但它们仍可预测 BMI 和结局。实际研究中应逐变量审查，而不是把 method = "pmm" 应用于所有类型。

插补次数不是固定的 5 或 10

所需 (m) 取决于缺失信息比例、目标估计量、需要的 Monte Carlo 精度以及计算成本。较少的插补数据集有时足以获得近似点估计，但尾部概率、置信区间和可重复性通常需要更多插补。实践中可先使用 20–50 个，再根据 Monte Carlo 误差和结果稳定性增加；高缺失信息量时可能需要更多。这里用 30 个数据集，是教学设置，不是通用阈值。

imp <- mice(
  analysis_data,
  m = 30,
  maxit = 15,
  method = method,
  predictorMatrix = predictor_matrix,
  seed = 20260731,
  printFlag = FALSE
)

插补诊断

诊断不等于寻找一个“通过/不通过”的数值。至少要检查迭代轨迹、观测值与插补值分布、异常值和各组的合理性。

plot(imp, c("bmi", "outcome"))

轨迹应在初始过渡后围绕稳定水平波动，且不同链充分混合。明显漂移或链间分离可能提示迭代不足、模型不稳定或变量关系设定错误。

densityplot(imp, ~bmi)

插补值不必与观测值分布完全相同，因为缺失可依赖其他变量；但极端不合理的范围、离散变量非法取值或临床上不可能的组合必须回到模型检查。

每个插补数据集必须使用同一预设模型。不要先 complete() 一个数据集再把它当作唯一分析结果。

pool() 合并的是模型估计与方差，不是原始数据。Rubin 法则的总方差包含：

  • 各插补数据集内的平均方差；
  • 不同插补数据集估计值之间的方差；
  • 有限 (m) 带来的额外不确定性。

完整案例结果可作为诊断性比较，但两种方法使用的目标样本和假设可能不同，差异不能简单归因于“MI 更准确”。

fit_cc <- lm(
  outcome ~ bmi + age + sex + smoke,
  data = analysis_data,
  na.action = na.omit
)

data.frame(

  bmi_estimate = c(
    coef(fit_cc)["bmi"],
    pooled_result$estimate[pooled_result$term == "bmi"]
  ),
  analysed_n = c(nobs(fit_cc), nrow(analysis_data))

交互、非线性与派生变量

如果最终模型含有 age^2、BMI 分类或暴露与时间的交互，直接先插补再重新计算派生变量有时会破坏关系。常见策略包括：

  • 被动插补：基础变量更新后同步计算确定性派生变量；
  • 实质模型相容插补：使插补模型显式兼容生存模型、非线性或交互；
  • 分层插补：仅在分层样本量和模型稳定性足够时使用。

选择取决于 estimand 和分析模型，不能把复杂项从插补模型中省略后期待 pool() 自动纠正。

哪些量不能直接平均

回归系数和可获得方差的标量通常可按 Rubin 法则合并。以下做法通常不正确：

  • 平均多个数据集的 p 值；
  • 平均逐步回归选出的不同模型；
  • 把一个插补数据集的诊断当作全部插补的诊断；
  • 对中位数、AUC、分位数或标准化风险直接套普通 pool()，却不说明方差估计。

非标准估计量可使用变换、pool.scalar()、bootstrap 与 MI 的适当组合，或该模型专用的合并方法。

常见错误

  1. 不含结局地插补协变量：在许多回归问题中会削弱协变量与结局的关系。
  2. 把所有数值变量都用 PMM：二分类、有序、多分类、计数和生存资料需要相应方法。
  3. 插补后删除“不理想”数据集：会破坏抽样机制，应解决模型或数据问题。
  4. 只报告 m，不报告模型：还需报告变量、方法、迭代、诊断、软件版本和随机种子。
  5. 把 MAR 当作已证实事实：应给出机制依据，并对合理的 MNAR 偏离做敏感性分析。
  6. 忽略聚类或纵向结构：单层插补可能低估簇内相关和不确定性。

报告清单

  • 各变量缺失数、缺失比例和主要缺失模式；
  • 缺失机制假设及临床或采集流程依据；
  • 插补变量、辅助变量、逐变量方法和预测矩阵原则；
  • (m)、迭代次数、随机种子与软件版本；
  • 收敛、分布和合理性诊断；
  • 合并规则、完整案例比较及 MNAR 敏感性分析；
  • 插补前后的实际分析样本定义。
