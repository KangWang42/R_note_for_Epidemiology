什么是 Claude Code

Claude Code 是 Anthropic 推出的官方 AI 编程助手，它直接在终端中运行，能够深度理解你的代码库，执行复杂的开发任务。与网页版 Claude 不同，Claude Code 具有代码感知能力——它可以读取、编辑、执行代码，并与你的开发环境深度集成。

核心特点

特性 说明
🧠 深度代码理解 自动分析项目结构，理解代码上下文和依赖关系
🔧 完整工具链 内置文件读写、代码搜索、Bash 执行、Git 操作等工具
🤖 智能代理系统 支持自定义 Agents 和 Skills，扩展 AI 能力
🔌 MCP 协议支持 通过 Model Context Protocol 连接外部工具和服务
📝 自然语言交互 用日常语言描述需求，AI 自动执行
🔄 Git 集成 自动跟踪文件变更，支持撤销/重做

适用场景

Claude Code 特别适合以下场景：

  • 代码生成与重构：根据自然语言描述自动生成代码，或重构现有代码
  • 代码审查：分析代码质量，发现潜在问题和改进点
  • 调试辅助：分析错误日志，定位并修复 Bug
  • 项目初始化：创建标准化的项目结构和配置文件
  • 文档生成：自动生成代码注释、API 文档和教程
  • 数据分析：执行 R/Python 脚本，生成分析结果和可视化
提示与网页版 Claude 的区别
功能 Claude Code Claude.ai 网页版
代码编辑 ✅ 可直接修改文件 ❌ 只能生成代码
项目感知 ✅ 理解整个代码库 ❌ 仅当前对话
工具执行 ✅ Bash/Git/文件操作 ❌ 无
本地运行 ✅ 数据不离开本地 ❌ 云端处理
代理系统 ✅ Skills/Agents/MCP ❌ 无

Claude Code 的独特优势：

  1. 研究级 AI 能力：基于 Claude 3.5/3.7 Sonnet，在代码理解和复杂推理方面表现优异
  2. 终端原生体验：无需离开终端，适合开发者工作流
  3. 智能委托机制：自动将任务分配给专门的子代理（Subagents）
  4. Skills 系统：通过技能包扩展 AI 的专业能力
  5. MCP 生态：连接数据库、API、文件系统等外部资源

安装指南

系统要求

  • 操作系统：macOS 10.15+、Windows 10+、Linux
  • Node.js：18.0 或更高版本
  • Git：用于版本控制集成
  • 终端：支持 ANSI 转义序列的现代终端

安装步骤

macOS / Linux

# 使用官方安装脚本
npm install -g @anthropic-ai/claude-code

# 或直接使用 npx（无需全局安装）
npx @anthropic-ai/claude-code

Windows

# 使用 PowerShell 安装
npm install -g @anthropic-ai/claude-code

# 或使用 npx
npx @anthropic-ai/claude-code

验证安装

claude --version

配置 API 密钥

Claude Code 需要 Anthropic API 密钥才能工作：

  1. 访问 Anthropic Console 注册账号
  2. 在 Settings → API Keys 中创建新密钥
  3. 配置环境变量：
# macOS / Linux (添加到 ~/.bashrc 或 ~/.zshrc)
export ANTHROPIC_API_KEY="sk-ant-api03-..."

# Windows PowerShell (添加到 $PROFILE)
$env:ANTHROPIC_API_KEY = "sk-ant-api03-..."
警告安全提示
  • 不要将 API 密钥硬编码在代码中
  • 使用环境变量或密钥管理工具（如 1Password、Bitwarden）
  • 定期轮换 API 密钥

基础使用

启动 Claude Code

# 在当前目录启动
claude

# 或指定项目目录
claude /path/to/your/project

# 使用特定模型
claude --model claude-sonnet-4-5

启动后，你会看到类似以下的界面：

文件操作

引用文件

使用 @ 符号引用项目中的文件，Claude 会自动读取并理解：

> @src/analysis.R 这个脚本的功能是什么？

> @data/survey.csv 帮我分析这个数据文件的结构

> @README.md 更新文档，添加安装说明

文件编辑

Claude Code 可以直接编辑文件：

> 在 src/utils.R 中添加一个计算 BMI 的函数

> 重构 @src/plotting.R，使用 ggplot2 替代 base R 绘图

> 修复 @src/model.R 第 45 行的语法错误

Bash 命令执行

使用 ! 前缀执行终端命令：

> !ls -la

> !Rscript src/analysis.R

> !git status

Claude 会显示命令输出，并根据结果提供建议。

高级功能

代理模式 (Agent Modes)

Claude Code 支持两种主要工作模式：

Build 模式（默认）

  • 启用所有工具：文件读写、代码编辑、Bash 执行
  • 适合需要 AI 修改代码的开发任务
  • 右下角显示 build 标识
> 帮我实现一个数据清洗函数
# Claude 会直接创建/修改文件

Plan 模式

  • 只读模式，禁用文件修改工具
  • 适合代码分析、方案设计、代码审查
  • 右下角显示 plan 标识
> /plan

> 我想重构这个项目的架构，请帮我设计一个方案
# Claude 只提供分析和建议，不修改文件

使用 Tab 键或 /build、/plan 命令切换模式。

会话管理

压缩会话

长时间对话会消耗大量 token，使用 /compact 压缩：

> /compact

Claude 会生成对话摘要，保留关键信息，同时大幅减少 token 消耗。

多会话切换

> /sessions

# 显示所有会话
# 1. 数据分析项目
# 2. 网站重构
# 3. 论文撰写

> /sessions 2  # 切换到会话 2

> /cost

创建自定义 Agent

在 ~/.claude/agents/ 目录创建 Markdown 文件：

---
name: r-analyst
description: R 语言数据分析专家
model: claude-sonnet-4-5
---

# R 数据分析专家

你是一个专业的 R 语言数据分析师，专注于流行病学和卫生统计。

## 核心职责

1. 编写高质量的 R 代码
2. 进行统计分析（描述统计、回归、生存分析）
3. 生成出版级图表
4. 撰写分析报告

## 编程规范

- 禁止使用 for 循环，使用 purrr::map_*()
- 使用 tidyverse 风格
- 使用 ggsci 配色
- 双格式导出图片（PNG + PDF）

## 工具权限

允许使用：
- 文件读写
- 执行 R 代码
- 生成图表

MCP 协议集成

Model Context Protocol (MCP) 是 Anthropic 推出的开放协议，用于连接 AI 与外部工具。

MCP 的工作原理

┌─────────────┐     MCP 协议      ┌─────────────┐
│ Claude Code │ ◄──────────────► │ MCP Server  │
│             │   标准化接口      │             │
└─────────────┘                  └──────┬──────┘
                                        │
                    ┌───────────────────┼───────────────────┐
                    ▼                   ▼                   ▼
              ┌─────────┐        ┌─────────┐        ┌─────────┐
              │ 数据库   │        │ 文件系统 │        │  API    │
              └─────────┘        └─────────┘        └─────────┘

常用 MCP Servers

Server 功能 安装
filesystem 文件系统访问 @anthropic-ai/mcp-server-filesystem
fetch 网页内容抓取 @anthropic-ai/mcp-server-fetch
memory 持久化记忆存储 @anthropic-ai/mcp-server-memory
sequential-thinking 复杂推理增强 @anthropic-ai/mcp-server-sequential-thinking
github GitHub API 集成 @modelcontextprotocol/server-github
postgres PostgreSQL 数据库 @modelcontextprotocol/server-postgres

配置 MCP Servers

编辑 ~/.claude/settings.json：

{
  "mcpServers": {
    "fetch": {
      "command": "npx",
      "args": ["-y", "@anthropic-ai/mcp-server-fetch"],
      "description": "网页内容抓取"
    },
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@anthropic-ai/mcp-server-filesystem", "/Users/you/projects"],
      "description": "文件系统访问"
    },
    "memory": {
      "command": "npx",
      "args": ["-y", "@anthropic-ai/mcp-server-memory"],
      "description": "持久化记忆存储"
    }
  }
}

场景实战

场景一：R 数据分析项目

背景：你有一个 CSV 文件，需要进行数据清洗和可视化分析。

步骤：

# 1. 启动 Claude Code 并进入项目目录
claude ~/my-analysis

# 2. 让 Claude 分析数据
> 读取 data/raw_data.csv，分析数据结构和质量问题

# 3. 数据清洗
> 创建一个数据清洗脚本，处理缺失值和异常值

# 4. 生成可视化
> 绘制年龄分布直方图和性别比例的柱状图

# 5. 生成报告
> 创建一个 RMarkdown 报告，包含数据摘要和可视化

进阶技巧：

  • 使用 @ 引用数据文件，让 Claude 理解数据结构
  • 要求 Claude 使用特定的 R 包（如 tidyverse）
  • 指定输出格式（PNG/PDF）和样式

场景二：代码重构

背景：你有一个遗留的 R 脚本，需要重构为 tidyverse 风格。

步骤：

# 1. 切换到 Plan 模式进行初步分析
> /plan

# 2. 分析现有代码
> @src/old_analysis.R 分析这个脚本的问题和改进空间

# 3. 获取重构建议
> 提供一个重构方案，将 base R 代码转换为 tidyverse 风格

# 4. 切换到 Build 模式执行重构
> /build

# 5. 执行重构
> 按照刚才的方案重构 @src/old_analysis.R

进阶技巧：

  • 先使用 Plan 模式分析，再使用 Build 模式执行
  • 要求 Claude 保留原始代码的注释
  • 让 Claude 生成重构前后的对比说明

场景三：学术论文写作

背景：你已经完成了数据分析，需要撰写论文的方法部分。

步骤：

# 1. 提供分析结果
> 基于以下结果撰写论文方法部分：
> - 使用了 Cox 比例风险模型
> - 样本量：n=1250
> - 主要发现：HR=1.45 (95%CI: 1.23-1.71)

# 2. 生成初稿
> 生成 600 字的方法部分，包含统计软件信息

# 3. 润色修改
> 使用更正式的学术语言润色这段文字

# 4. 格式调整
> 按照 BMJ 的格式要求调整参考文献格式

进阶技巧：

  • 提供期刊的投稿指南，让 Claude 按格式要求撰写
  • 使用 academic-humanizer 锁定数字、引文、公式和论断方向，再进行学术审校
  • 使用 academic-publishing 按方法、结果、讨论、引言、摘要和题名逐部件完成并检查

提示词工程

原则 1：具体明确

❌ 不好的提示：

> 分析这个数据

✅ 好的提示：

> 对 data/survey.csv 进行描述性统计分析，
> 计算年龄、BMI 的均值±标准差，
> 按性别分组，输出到 results/table1.xlsx

原则 2：提供上下文

> 这是一个队列研究数据，
> 结局变量是 cardiovascular_event（0/1），
> 主要暴露是 smoking_status（Never/Former/Current），
> 请进行 Cox 回归分析，调整年龄、性别、BMI

原则 3：分步骤执行

> 第一步：读取并检查数据质量
> 第二步：创建 Table 1（基线特征表）
> 第三步：进行生存分析，绘制 KM 曲线
> 第四步：执行 Cox 回归
> 第五步：生成森林图展示结果

常见问题与解答

Q: Claude Code 和 Claude.ai 网页版有什么区别？

A: Claude Code 是终端应用，具有代码感知和工具执行能力；网页版只能通过对话交互，无法直接操作文件。

Q: 如何让 Claude 记住我的项目偏好？

A: 创建 CLAUDE.md 文件放在项目根目录，Claude 会自动读取并遵循其中的规则。

Q: Claude Code 支持哪些编程语言？

A: 支持所有主流语言，包括 R、Python、JavaScript、TypeScript、Go、Rust 等。

Q: 可以离线使用吗？

A: 不可以，Claude Code 需要联网调用 Anthropic API。

Q: 如何撤销 AI 的修改？

A: 使用 /undo 命令，或借助 Git 进行版本回退。

Q: 费用如何计算？

A: 按 API 调用量计费，输入和输出 tokens 分别计费。使用 /cost 查看当前会话费用。

Q: 支持团队协作吗？

A: 支持。将 CLAUDE.md 提交到 Git，团队成员共享相同的 AI 规则。

Q: 如何处理网络代理？

A: 设置 HTTPS_PROXY 环境变量：

export HTTPS_PROXY="http://127.0.0.1:7890"

总结

Claude Code 是一款强大的 AI 编程助手，特别适合：

  • 研究人员：快速进行数据分析和论文撰写
