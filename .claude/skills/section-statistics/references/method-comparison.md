# 统计方法辨析

本表只用于提出候选方法。最终选择由研究问题、estimand、数据生成过程和设计决定。

| 问题 | 常见候选 | 必须先核对 |
|---|---|---|
| 连续结局的条件均值 | 线性模型、GAM、稳健或分位数回归 | 均值函数、非线性、方差结构、异常影响；不是要求结局本身必须正态 |
| 二分类结局 | logistic、log-binomial、Poisson 稳健方差 | 目标是 OR、风险比还是风险差，随访和抽样设计 |
| 计数或率 | Poisson、负二项、零膨胀/障碍模型 | offset、过度离散、结构零和随访时长 |
| 相关或纵向数据 | GEE、混合效应模型、经典重复测量方差分析 | 总体平均还是个体异质性/条件效应，固定访视还是不规则时间，簇数、缺失机制、相关或协方差结构、球形性 |
| 时间到事件 | KM、Cox、参数或灵活参数模型 | 时间零点、删失、PH、绝对风险和时间尺度 |
| 竞争事件 | CIF、原因别 Cox、Fine–Gray | 目标是原因别过程还是累积发生；sHR 不是普通瞬时 HR |
| 时变暴露 | 起止时间 Cox、MSM、g-formula | 暴露更新时序、时变混杂；时变协变量不等于时变系数 |
| 缺失数据 | 完整案例、MI、加权、联合/敏感性模型 | MCAR/MAR/MNAR 假设、插补与分析模型相容性 |
| 多重检验 | Holm/Bonferroni、BH/BY、分层方法 | 检验族、FWER 或 FDR、筛选是否使用当前数据 |
| 样本量 | 功效、精度、事件数、模拟 | 主要 estimand、目标差异、变异、失访、设计效应与分析模型 |

## 关键边界

- PH 违背涉及系数随时间变化；加入一个会更新的时变协变量不能自动修复。
- PSM、IPTW、DiD、IV 和 RDD 依赖不同识别假设，不能按软件易用性互换。
- 已测量协变量平衡不证明没有未测量混杂。
- Fine–Gray 与原因别 Cox 回答不同问题，数值不同不表示其中一个错误。
- “每变量 10 个事件”、SMD 0.1、5 次插补和固定权重截断都不是普适规则。

## 纵向重复测量的前置定位

GEE、混合效应模型和经典重复测量方差分析都可处理同一受试者的多次观测，但不能仅按软件熟悉度互换。写教程时至少说明：

| 维度 | GEE | 混合效应模型 | 经典重复测量方差分析 |
|---|---|---|---|
| 主要目标 | 边际或总体平均效应 | 固定效应与个体/簇间异质性；非线性链接下回归系数通常条件于随机效应 | 预设固定时间点的组别、时间及交互均值比较 |
| 相关性处理 | 工作相关矩阵与 sandwich 方差 | 随机效应和/或残差协方差模型 | 被试内因子及球形性等协方差约束 |
| 个体差异 | 不直接估计随机效应或个体轨迹 | 可估计方差分量并描述个体轨迹 | 通常不以灵活的随机效应结构描述个体异质性 |
| 数据形态 | 可处理每簇观测数不同，但有效性仍依赖簇数、均值模型和缺失假设 | 可处理不平衡与不规则时间，但需正确指定均值、随机效应/协方差和缺失假设 | 更适合共同固定时间点且数据较完整的规则设计 |
| 关键检查 | 簇定义与数量、均值模型、工作相关结构、稳健方差和影响簇 | 随机效应/协方差结构、收敛、残差、奇异拟合和外推 | 球形性、校正方式、完整案例变化及交互解释 |

不要把“LMM 能处理缺失”写成无条件保证：基于似然的推断仍依赖模型正确性及可忽略缺失等条件。也不要把 GEE 的稳健方差写成均值模型、簇定义、少簇问题和信息性失访都可以忽略。线性恒等链接下两类模型的固定效应可能具有相近的边际解释；总体平均与条件效应的差异在非线性链接模型中尤其重要。
