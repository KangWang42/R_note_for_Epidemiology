## 2. 必须遵循的一级标题 (##) 层次
1. `## 方法背景与适用场景`: 用途、设计类型、数据要求、方法对比。
2. `## 核心概念与模型入门`: **零基础通俗解释**、术语定义、数学模型。
3. `## 模型假设与前提条件`: 关键假设、含义、检验方法、违背后果。
4. `## 数据准备`: 变量说明、清洗步骤、模拟数据生成。
5. `## 完整分析流程`: 探索性分析 -> 模型拟合 -> 模型诊断 -> 结果解释。
6. `## 结果解读与报告`: 统计量含义、效应量、P值解读、论文报告格式。
7. `## 常见错误与纠偏`: 5-10个常见错误及其对策。
8. `## 进阶扩展`: 替代方法、高级应用、推荐阅读。
9. `## 总结`
10. `## 参考文献`

## 3. 零基础通俗解释规范
必须先用生活化例子解释核心原理，例如：
- **PSM**: 找"双胞胎"进行公平比较。
- **非参数检验**: 赛跑只看排名，不看具体快多少。
- **生存分析**: 既看"去世"的，也看"还活着"的。

## 4. 分析流程框架
每个步骤遵循：`步骤说明 → 为什么需要这步 → 代码实现 → 代码逐行解释 → 输出解读`。
