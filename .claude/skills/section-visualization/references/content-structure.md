# 数据可视化教程结构

## 先定义图的问题

开头说明图要比较、展示或诊断什么，所需变量类型和最终载体。若图包含统计估计，定义分母、效应尺度和不确定性。

## 可选模块

1. 适用问题、数据形态及容易混淆的替代图；
2. 图形编码或统计变换的含义；
3. 最小数据和最小可运行图；
4. 对输出的逐图解读；
5. 排序、分组、区间、分面、标注或主题改进；
6. 尺度、缺失、重叠、样本量和误导风险；
7. 无障碍、目标尺寸导出和复现信息。

简单图形可以很短；复合图、空间图、网络图或统计诊断图应展开数据变换和解释边界。不要强制“基础—中级—高级”三组示例。

## 示例节奏

每个关键示例使用：读图问题 → 代码 → 图中模式 → 限制或下一步。多次改图时保留新增能力的差异，避免复制整段代码只修改一个色值。
