# 入门教程图件选择

## 优先使用真实产物

- R 对象、数据变化和绘图结果：由文章代码实际生成。
- RStudio、Positron、终端和设置界面：使用当前版本的真实截图，并裁掉无关信息和凭证。
- Quarto、R Markdown 和文档：渲染最小文件后展示真实页面。
- 文件树：简单层级优先用可复制的文本代码块。

## 何时生成内容图

学习路线、对象层级或多步数据流只有在关系用短文和表格难以追踪时才使用 `research-visuals`。图中术语必须来自正文或官方资料，不把手写 SVG 模板作为默认方法。

候选图应回答一个明确问题，例如“对象从哪一步变成哪种结构”或“读者下一步应去哪里”。删除后不损失理解的装饰图不进入正文。每张图提供替代文本，正文说明读图重点和适用边界。
