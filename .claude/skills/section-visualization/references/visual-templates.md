# 可视化教程图件与导出

## 图件来源

教程中的示例图、对比图和诊断图均由真实代码与数据对象生成。只有需要解释 ggplot2 图层关系、选择分支或多步骤布局时，才按 `research-visuals` 生成非统计内容图；不默认制作封面或手写 SVG。

## 输出合同

在导出前锁定载体和实际尺寸：

| 载体 | 优先检查 |
|---|---|
| 网站 | 响应式宽度、移动端图例、替代文本、资源路径 |
| 论文 | 期刊栏宽、物理字号、线宽、灰度与矢量/位图要求 |
| 演示 | 远距离可读、信息密度、16:9 页面中的实际占比 |
| 海报 | 最终印刷尺寸、观察距离、分辨率和嵌入字体 |

不要用固定像素模板替代目标载体规范。导出后重新打开最终 PNG/SVG/PDF，核对裁切、字体替换、透明背景和图例位置。

## 读图合同

每张图前写读图问题，图后说明观察到的模式和不能由该图推出的结论。比较版式时保持数据、尺度和统计变换相同，否则视觉差异无法归因于设计选择。
