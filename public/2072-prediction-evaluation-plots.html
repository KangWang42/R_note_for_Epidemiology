三类图回答三个问题

预测模型常被一条 ROC 曲线概括，但 ROC 只回答模型能否把较高风险更多地分配给事件个体。预测概率是否接近实际风险，需要校准图；在给定决策阈值下使用模型是否比“全部干预”或“均不干预”带来更高净获益，需要决策曲线。三者不能互相替代。

本教程在一份独立模拟验证集中完成绘图。读完后，你可以从模型预测概率构造四类图，并能解释图的分母、参考线和限制。模拟结果只用于教学，不构成模型性能证据。

图形 主要问题 横纵轴 不能推出的结论
按结局分组的预测分布 两类个体的预测值重叠多少 预测概率与组内密度 不能直接读出总体事件率
ROC 曲线 不同阈值下灵敏度与特异度怎样权衡 1−特异度与灵敏度 AUC 高不代表概率校准良好
校准图 预测风险是否接近观察风险 平均预测风险与观察比例 分箱图不能替代完整校准评估
决策曲线 特定阈值范围内净获益是否更高 阈值概率与净获益 不能脱离临床后果定义阈值

构造开发集与独立验证集

为了避免把训练拟合度当成泛化性能，下面分别生成开发集和验证集。验证集的基线风险略高，因此即使模型排序能力尚可，校准也可能发生偏移。这种设置能让不同评估图各自暴露一类问题。

library(ggplot2)
library(dplyr)
library(pROC)
library(dcurves)
library(scales)

simulate_binary_data <- function(n, seed, intercept_shift = 0) {
  set.seed(seed)
  age <- pmin(85, pmax(35, rnorm(n, mean = 61, sd = 10)))
  biomarker <- rnorm(n)
  prior_event <- rbinom(n, size = 1, prob = 0.28)
  linear_predictor <- -1.75 + intercept_shift +
    0.035 * (age - 60) + 0.90 * biomarker + 0.62 * prior_event

  tibble(
    age = age,
    biomarker = biomarker,
    prior_event = factor(prior_event, levels = c(0, 1)),
    event = rbinom(n, size = 1, prob = plogis(linear_predictor))
  )
}

development <- simulate_binary_data(900, seed = 2072)
validation <- simulate_binary_data(650, seed = 2073, intercept_shift = 0.28)

prediction_model <- glm(
  event ~ age + biomarker + prior_event,
  data = development,
  family = binomial()
)

validation <- validation |>
  mutate(
    predicted_risk = predict(prediction_model, newdata = validation, type = "response"),
    outcome = factor(event, levels = c(0, 1), labels = c("No event", "Event"))
  )

validation |>
  summarise(
    n = n(),
    events = sum(event),
    event_rate = mean(event),
    mean_predicted_risk = mean(predicted_risk)
  )

预测分布：先看重叠而非只看均值

将预测概率按实际结局分组，可以直接观察排序信息来自哪里。密度曲线在每个结局组内归一化，因此适合看形状和重叠，不适合比较两组人数或总体事件率。

ROC 曲线：展示阈值权衡

pROC::roc() 根据连续预测值计算 ROC 对象。绘图时将特异度转换为假阳性率，并保留 45 度无信息参考线。AUC 及其置信区间来自同一个 ROC 对象，避免图和正文使用不同口径。

roc_object <- pROC::roc(
  response = validation$event,
  predictor = validation$predicted_risk,
  levels = c(0, 1),
  direction = "<",
  quiet = TRUE
)

roc_curve <- tibble(
  false_positive_rate = 1 - roc_object$specificities,
  sensitivity = roc_object$sensitivities
) |>
  arrange(false_positive_rate, sensitivity)

auc_ci <- as.numeric(pROC::ci.auc(roc_object, method = "delong"))

ROC 曲线把所有阈值连接起来，但并未说明哪一段阈值具有临床意义。AUC 是随机抽取一名事件个体和一名无事件个体时，前者获得更高预测值的概率解释；它不等于准确率，也不报告概率误差。

校准图：预测风险与观察风险是否一致

下面将验证集按预测概率分为十分位组。每个点的横坐标是组内平均预测风险，纵坐标是观察事件比例，误差线是 Wilson 95% 区间。45 度线表示理想一致。分组校准图便于发现明显偏移，但点的位置依赖分箱方式。

wilson_interval <- function(events, total, level = 0.95) {
  z <- qnorm(1 - (1 - level) / 2)
  proportion <- events / total
  denominator <- 1 + z^2 / total
  centre <- (proportion + z^2 / (2 * total)) / denominator
  half_width <- z * sqrt(
    proportion * (1 - proportion) / total + z^2 / (4 * total^2)
  ) / denominator

  tibble(
    lower = pmax(0, centre - half_width),
    upper = pmin(1, centre + half_width)
  )
}

calibration_points <- validation |>

决策曲线：在有意义阈值内比较净获益

阈值概率 \(p_t\) 表示采取干预所需的最低预测风险。二分类结局的常用净获益为

\[ \mathrm{NB}=\frac{\mathrm{TP}}{n}-\frac{\mathrm{FP}}{n}\frac{p_t}{1-p_t}. \]

公式把假阳性的代价按阈值换算到真阳性尺度。下面只画预先限定的 5% 至 40% 教学阈值范围，并同时保留“全部干预”和“均不干预”参考策略。实际范围应来自具体决策情境，而不是观察曲线后挑选。
