## 1. YAML 头部与 Setup
```yaml

categories:
- 入门指南
- [其他相关分类]

---

## 2. 必须遵循的标题层次 (CRITICAL)
- 一级标题 (`##`) 是生成目录的唯一途径。
- 文章必须包含至少 3 个一级标题。
- 单个 `#` 标题由 Quarto 自动生成，禁止手动添加。

## 3. 章节结构规范
1. `## 教程目标与适用场景`: 明确学习目标、适合人群、前置知识、学完掌握技能。
2. `## 学习路线图`: 阶段划分（入门 → 进阶 → 实战）、学习重点、推荐顺序。
3. `## 核心概念详解`: 从 0 开始讲解，用类比/比喻解释术语，提供对比表格。
4. `## 环境准备与安装`: R/RStudio 安装指引、必要 R 包安装、常见问题解决。
5. `## 实践步骤 (核心)`: 遵循 "概念讲解 → 代码示例 → 逐行解释 → 输出说明 → 常见变体"。
6. `## 常见错误与解决方案`: 列出 5-10 个新手常犯错误及其对策。
7. `## 进阶扩展`: 后续学习方向、推荐资源、相关教程链接。

## 4. 写作规范
- **文字比例**: 目标比例 70% 文字 + 30% 代码。
- **通俗易懂**: 假设读者完全不懂，避免直接堆砌专业术语。
- **代码规范**: chunk label 必须清晰，随机操作设置种子 `set.seed(2026)`。
- **标题层级**: 不要手动编号，使用中文标题。
