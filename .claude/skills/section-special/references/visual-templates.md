# 特殊应用图件选择

## 按证据属性选择来源

| 内容 | 正确来源 |
|---|---|
| 成本效果平面、可接受曲线、信号谱、滞后曲线、模拟分布 | 文章代码与真实结果对象 |
| 商业软件、设备界面、终端和报告页面 | 实际运行或官方允许使用的真实截图 |
| 方法流程、状态转移、机制和跨领域框架 | `research-visuals` 规定的生成与审查流程 |
| 生理信号、显微、影像及其他科研原始图像 | 原始文件和允许的确定性处理，不生成式重绘 |

## 领域检查

- 卫生经济学图注明货币单位、成本年、阈值与不确定性来源。
- 信号图注明单位、采样率、时间/频率尺度和预处理；不能只展示处理后“漂亮”波形。
- 环境暴露图注明暴露窗口、滞后、空间时间分辨率与置信区间。
- 模拟图区分单次轨迹、重复分布、校准数据和外部验证。
- 质性结果图只呈现真实编码与研究者复核后的结构，不由生成式工具补主题或关系。

不强制封面、两张示意图、固定画布或 SVG。每张图必须有独立信息贡献、准确替代文本和正文解读；删除后不损失理解的装饰图不进入文章。
