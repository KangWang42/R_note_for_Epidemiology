## 2. 必须遵循的标题层次 (CRITICAL)
- 一级标题 (`##`) 是生成目录的唯一途径。
- 文章必须包含至少 3 个一级标题。
- 单个 `#` 标题由 Quarto 自动生成，禁止手动添加。

## 3. 章节结构规范
1. `## 简介`: 包含对比表格（图表类型、展示信息、优点、缺点、适用场景）。
2. `## 图形构成解析`: 详细解释图表元素（如箱线图的箱体、中线、须等）。
3. `## 数据准备`: 说明变量类型、数据格式，并提供示例数据。
4. `## 基础图表绘制`: 从最简单版本开始，解释核心函数。
5. `## 样式美化与定制`: 分层次展示填充颜色、主题设置、坐标轴调整。
6. `## 进阶技巧`: 展示添加统计信息、分面显示、组合图表。
7. `## 实战案例`: 提供完整场景、代码与最终效果。
8. `## 常见错误与解决`: 列出 5-10 个常见问题。
9. `## 输出与保存`: 说明如何保存高质量图片。
10. `## 进阶扩展`: 推荐资源与相关链接。

## 4. 写作规范
- **图文比例**: 每个代码块都有对应的图表输出，每张图必须有文字解释。
- **代码规范**: 渐进式展示代码，使用有意义的 chunk 命名。
- **配色规范**: 优先使用 ggsci、ColorBrewer 或 viridis。
- **图表注释**: 必须包含标题、坐标轴标签、图例标题。
