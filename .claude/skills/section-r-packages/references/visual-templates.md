# R 包教程图件选择

## 首选真实产物

- 模型包：预测、残差、校准、权重或敏感性图；
- 绘图包：由教程代码直接生成的代表性图；
- 文档与排版包：实际编译页面或真实界面截图；
- 数据处理包：小型输入与输出表，或确有必要的步骤关系图；
- 微分方程与插值包：函数返回对象绘制的真实轨迹和节点。

不要强制每篇生成架构 SVG，也不要用圆形辐射图代替函数关系。只有删除后会使包的输入、模块或调用方向难以理解时，才按 `research-visuals` 生成结构图。

图件必须标注生成脚本或代码来源、包版本和关键输入。统计图遵循 `publication-figures`，真实界面通过实际运行获取。
