## 2. 必须遵循的标题层次 (CRITICAL)
- 一级标题 (`##`) 是生成目录的唯一途径。
- 文章必须包含至少 3 个一级标题。
- 单个 `#` 标题由 Quarto 自动生成，禁止手动添加。

## 3. 章节结构规范
1. `## 教程目标`: 介绍算法/框架、适用场景、不适用场景、算法对比表格。
2. `## 算法原理`: 核心思想（通俗解释）、工作机制、数学表达、关键超参数。
3. `## ML 工作流程概览`: 提供从数据准备到部署的完整流程图。
4. `## 数据准备`: 数据加载、EDA、数据划分 (Train/Test)、特征工程 (recipes)。
5. `## 模型训练`: 基线模型建立、目标模型训练 (mlr3/tidymodels)、参数说明。
6. `## 模型评估`: 预测、评估指标 (ACC/AUC/F1)、混淆矩阵、ROC 曲线、交叉验证。
7. `## 超参数优化`: 定义搜索空间、网格搜索/随机搜索、使用最优参数重新训练。
8. `## 模型可解释性`: 特征重要性提取与可视化、SHAP 值分析 (可选)。
9. `## 保存模型`: 保存训练好的模型与预处理器、加载与新数据预测。

## 4. 写作规范
- **完整性**: 必须包含完整的训练-评估-优化流程。
- **可复现性**: 所有随机操作必须设置种子 `set.seed(2026)`。
- **框架选择**: 推荐使用 `mlr3` 或 `tidymodels` 现代框架。
- **理论比例**: 核心原理简明扼要 (20%)，实践流程详尽 (80%)。
