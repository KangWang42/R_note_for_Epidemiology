# R 包教程结构

## 必需信息

- 包的任务定位、当前版本、发布渠道、许可证和官方资源；
- 与底层实现、同类包或生态系统的关系；
- 安装与版本核对，不把加载成功当作功能验证；
- 按任务组织的核心函数、输入类型和返回对象；
- 最小示例与至少一个完整工作流；
- 诊断、失败输入、性能或适用边界；
- 可复现记录和进一步阅读。

标题由包的实际能力决定，不强制“性能优化”章节。若没有公平基准，不做性能排行；若包只是薄封装，应把重点放在统一接口、返回结构和方法边界。

## 示例层次

1. 用最短代码证明安装版本与基本接口；
2. 用一个真实任务串联多个函数；
3. 展示如何读取返回对象、检查诊断或错误；
4. 给出与 tidyverse、模型对象或文件格式的组合方式；
5. 说明哪些情形应直接使用底层包或其他工具。

参数解释优先覆盖会改变 estimand、算法、时间单位、缺失处理、随机性、并行或输出格式的参数。
